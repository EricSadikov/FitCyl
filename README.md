Команды FITCYL, FITCON, FITCIRS:
Выбираем первое сечение, нажимаем Enter, выбираем первое сечение, нажимаем Enter, программа предложит ввести нужные радиусы (слитно через запятую). Если не вводить - радиусы подсчитаются автоматически. Если ввести один радиус, то они будут одинаковы.
FITCIR2d и FITCIR3D - аппроксимация окружностью. Так же можно задать конкретный радиус.
